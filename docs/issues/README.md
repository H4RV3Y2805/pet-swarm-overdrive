# Outstanding work as GitHub issues

One file per issue. First line is the title, the `Labels:` line lists labels, the rest is the body. To create them on GitHub, ask Claude Code:

> Create one GitHub issue per file in docs/issues (not this README) with `gh issue create`, using the first heading as the title and the rest as the body. Create any missing labels first. Then list the issue numbers.
